# C语言学生信息管理系统

## 项目简介

这是一个使用 C 语言开发的控制台学生信息管理系统，用于练习结构体、数组、函数、文件操作和模块化编程。

## 当前功能

- 添加学生信息
- 显示全部学生信息
- 输入错误处理

## 计划功能

- 按学号查询学生
- 修改学生信息
- 删除学生信息
- 按成绩排序
- 成绩统计
- 文件保存和读取

## 学生信息

每名学生包含学号、姓名和成绩。

## 开发环境

- Windows
- Visual Studio Code
- GCC（MinGW）
- Git

## 编译方法

在项目根目录运行：

```powershell
gcc src\main.c -o student-system.exe
```

## 运行方法

```powershell
.\student-system.exe
```

## 使用说明

运行程序后，输入菜单编号选择功能。当前已实现菜单中的添加学生和显示全部学生功能。
