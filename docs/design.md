# 设计说明

## 需求分析

系统需要在控制台中管理学生的学号、姓名和成绩，并提供增删改查、排序、统计以及数据持久化功能。程序应能处理错误输入，避免重复学号和非法成绩。

## 数据结构

```c
typedef struct
{
    int id;
    char name[50];
    float score;
} Student;
```

程序使用固定长度结构体数组保存最多 100 条记录。该设计符合本课程的数组、结构体和函数知识范围，便于理解和测试。

## 模块划分

| 模块 | 职责 |
|---|---|
| `main.c` | 显示菜单、读取输入、调用业务函数 |
| `student.c` | 增删改查、排序、统计等业务逻辑 |
| `storage.c` | 从文件加载和向文件保存学生记录 |
| `test_student.c` | 使用断言验证主要功能和边界条件 |

## 关键设计决策

1. 学号必须为正整数且不能重复。
2. 姓名不能为空，最长保存 49 个字符。
3. 成绩限定为 0～100。
4. 排序采用冒泡排序，便于结合数据结构课程理解算法过程。
5. 文件存储使用二进制格式，保存数组有效长度和结构体记录。
6. 输入统一通过 `fgets` 读取，再转换为数字，避免 `scanf` 残留换行导致的输入问题。

## 程序流程

```text
启动 -> 读取数据文件 -> 显示菜单 -> 执行功能 -> 返回菜单
                                      |
                                      +-> 退出 -> 保存数据 -> 结束
```
